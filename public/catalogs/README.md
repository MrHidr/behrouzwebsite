# Behrouz catalog PDF files

Place the complete catalog at:

`public/catalogs/behrouz-products-catalog.pdf`

Optional category-specific catalogs go in `public/catalogs/categories/` using
the category slug as the filename:

- `sauces.pdf`
- `canned.pdf`
- `jam.pdf`
- `pickles.pdf`
- `gherkin.pdf`
- `lime-juice.pdf`

The catalog widget checks these paths automatically and enables each download
as soon as its PDF exists.
